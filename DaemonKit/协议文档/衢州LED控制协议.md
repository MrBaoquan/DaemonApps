# KSV 系列 LED 控制器开发手册 (V1.2)

## 一、 开发核心规范（重要）

在调用任何指令前，请开发者务必阅读并实现以下逻辑，否则可能导致指令执行无效：

1.  **网口连接授权（仅 TCP 模式）：** 
    *   **必要前置：** 在建立 TCP 连接后，**必须先发送一次“设备连接指令”**。只有在授权成功后，后续的亮度或切换指令才会被执行。
    *   **重连逻辑：** 若发生网络中断、设备重启或网线拔插，TCP 链路重建后，必须**再次发送**“设备连接指令”重新授权。
2.  **参数持久化（固化）：** 
    *   亮度、对比度等调节默认仅保存在内存中，断电后会重置。若需关机后依然保持当前亮度，调节完成后必须发送一次**“固化设置 (0x95)”**指令。
3.  **校验和 (Checksum) 逻辑：** 
    *   所有下发指令均包含校验位。若修改了亮度数值，请务必更新校验位，否则设备将静默忽略该指令。

## 二、 通信接口配置

### 2.1 网口 (TCP)
*   **角色：** 设备作为 TCP Server，控制端作为 TCP Client。
*   **默认服务端 IP：** `192.168.0.100` (端口：`18100`)。

### 2.2 串口 (RS232)
*   **波特率：** `115200` | **数据位：** `8` | **停止位：** `1` | **校验：** `None`。

## 三、 关键指令集（网口 TCP 模式）

*适用于：KSV24c, KSV12c*

### 1. 设备连接（授权）指令
*   **下发：** `D2 02 96 49 1C 00 00 00 00 00 00 00 01 01 80 00 E9 00 01 00 00 EA 0D 0A 2E FD 69 B6`
*   **说明：** 连接 TCP 后首条必发指令。

### 2. 设置亮度与对比度
*   **下发：** `D2 02 96 49 1A 00 00 00 00 00 00 00 21 20 06 00 00 AC 01 3A [对比度] [亮度] 2E FD 69 B6`
*   **参数：** 亮度/对比度均为十六进制 `0x00 - 0xFF`。

### 3. 读取当前亮度/对比度
*   **下发：** `D2 02 96 49 1A 00 00 00 00 00 00 00 22 20 06 00 00 AB 11 3A 00 02 2E FD 69 B6`
*   **返回：** `D2 02 96 49 16 ... 22 20 02 00 [对比度] [亮度] 2E FD 69 B6`

---

## 四、 关键指令集（串口 RS232 模式）

*适用于：KSV6c, KSV8c, KM2, KM4, KLS 系列等*

### 1. 亮度设置 (0x93)
*   **下发：** `E9 00 93 [亮度值] 00 [Sum] 0D 0A`
*   **说明：** 若亮度值改变，必须重新计算 Sum（计算规则见第六部分）。

### 2. 对比度设置 (0x94)
*   **下发：** `E9 00 94 [对比度值] 00 [Sum] 0D 0A`

### 3. 固化设置 (0x95) —— 关机记忆
*   **下发：** `E9 00 95 00 00 7E 0D 0A`
*   **作用：** 将当前亮度/对比度永久写入存储，下次开机自动应用。

### 4. 获取亮度状态逻辑
*   **文档说明：** 串口协议未提供独立查询指令。
*   **推荐方案：** 
    1. **状态回传：** 每次发送设置指令（0x93）后，设备返回的 Data1 字节即为设备确认后的实时亮度值。
    2. **本地缓存：** 初始化时由控制端强制下发一次预设亮度，随后在软件本地维护状态。

## 五、 屏幕开关逻辑（通用）

本系列设备不提供物理电源断电指令，通过**亮度零点映射**实现黑屏（关屏）与亮屏（开屏）效果：

*   **关闭屏幕（黑屏）：** 调节亮度值为 `0x00`。
    *   网口：将对应亮度位设为 `00` 下发。
    *   串口：`E9 00 93 00 00 7C 0D 0A`
*   **开启屏幕：** 调节亮度值为目标亮度（如 100 对应 `0x64`）。
    *   串口：`E9 00 93 64 00 E0 0D 0A`

## 六、 开发者算法实现

### 1. 亮度百分比换算
UI 界面滑块（0-100%）与指令（0x00-0xFF）的对应关系：
*   $指令值 = \text{floor}(\text{UI百分比} \times 2.55)$
*   例如：80% 亮度 $\approx$ 204 $\rightarrow$ `0xCC`

### 2. 校验和 (Sum) 计算公式
针对串口及网口部分指令，校验计算范围为帧头开始到校验位前的字节累加，取低 8 位。
```csharp
// 串口 Sum 计算示例 (C#)
byte CalculateSum(byte[] cmd) {
    int total = 0;
    for (int i = 0; i < 5; i++) { // 对前5位 E9 00 93 Data1 Data2 求和
        total += cmd[i];
    }
    return (byte)(total & 0xFF); 
}
```

### 3. 错误处理
当接收到设备回传数据时，解析 `Data2` 字段：
*   `0x01` / `0xFF`：执行成功。
*   `0x00` / `0xEE`：执行失败（请检查指令格式或连接授权）。

## 七、 模式调用 (快速场景切换)
若已在设备上手动保存了模式，可通过以下指令快速调用模式：
*   **调用模式 01：** `E9 00 11 01 00 FB 0D 0A`
*   **调用模式 02：** `E9 00 11 02 00 FC 0D 0A`
