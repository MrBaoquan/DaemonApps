# Hook 文本输入问题修复 - 快速参考\n\n## 问题\n✗ Hook 模式下授权码输入框无法输入/粘贴文本\n\n## 原因\nGetMessage Hook 无法正确处理 `WM_CHAR` 消息转换（依赖应用主循环的 `TranslateMessage`）\n\n## 解决\n改用 `WH_KEYBOARD` Hook，在 Hook 中直接用 `ToUnicodeEx()` 转换键码为字符\n\n---\n\n## 修改文件\n\n### 1. [HookRenderer.h](HookRenderer.h#L78-L82)\n```diff\n- HHOOK m_hGetMsgHook = nullptr;\n- static LRESULT CALLBACK GetMsgHookProc(...);\n+ HHOOK m_hKeyboardHook = nullptr;  // ← 改为 WH_KEYBOARD\n```\n\n### 2. [HookRenderer.cpp](HookRenderer.cpp)\n\n#### 2.1 添加头文件\n[L8](HookRenderer.cpp#L8)：\n```diff\n #include <windows.h>\n #include <tlhelp32.h>\n+#include <winuser.h>\n```\n\n#### 2.2 实现 KeyboardHookProc()\n[L444-511](HookRenderer.cpp#L444-L511)：\n```cpp\nLRESULT CALLBACK HookRenderer::KeyboardHookProc(int nCode, WPARAM wParam, LPARAM lParam) {\n    if (nCode < 0) return CallNextHookEx(...);\n    if (!s_instance || !ImGui::GetCurrentContext()) return CallNextHookEx(...);\n    \n    LPKBDLLHOOKSTRUCT p = reinterpret_cast<LPKBDLLHOOKSTRUCT>(lParam);\n    ImGuiIO& io = ImGui::GetIO();\n    \n    switch (wParam) {\n        case WM_KEYDOWN:\n        case WM_SYSKEYDOWN: {\n            io.KeysDown[vkey] = true;\n            \n            // 关键：在 Hook 中转换键码为字符\n            if (vkey >= 0x30 && vkey <= 0x5A) {\n                BYTE keyState[256] = {};\n                GetKeyboardState(keyState);\n                wchar_t outChar[4] = {};\n                \n                int result = ToUnicodeEx(\n                    vkey, p->scanCode, keyState,\n                    outChar, 4, 0, GetKeyboardLayout(0)\n                );\n                \n                if (result > 0 && outChar[0] >= 0x20) {\n                    io.AddInputCharacter((unsigned int)outChar[0]);\n                }\n            }\n            break;\n        }\n        case WM_KEYUP:\n        case WM_SYSKEYUP:\n            io.KeysDown[vkey] = false;\n            break;\n    }\n    return CallNextHookEx(s_instance->m_hKeyboardHook, nCode, wParam, lParam);\n}\n```\n\n#### 2.3 更新
