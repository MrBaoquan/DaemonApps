# Hook 模式文本输入修复 - 测试指南\n\n## 前置条件\n\n### 编译要求\n✅ 使用修复后的代码编译 LicHper.dll\n```powershell\nmsbuild LicHper\\LicHper.vcxproj /p:Configuration=Debug /p:Platform=x64\n```\n\n### 环境要求\n- Windows 10/11\n- 支持 DirectX 11 的应用（Unity、Unreal Engine 等）\n- 无有效授权码\n\n---\n\n## 测试场景\n\n### 场景 1: 基础文本输入\n\n**步骤**：\n1. 启动无授权的 DirectX 应用\n2. 水印 + 授权窗口出现\n3. 点击授权码输入框\n4. 依次输入：`test123ABC`\n\n**预期结果**：\n- 输入框中显示 `test123ABC`\n- 光标随输入移动\n- 无卡顿\n\n**失败症状**：\n- 输入框仍为空\n- 无光标闪烁\n- → 问题未修复\n\n---\n\n### 场景 2: 删除与编辑\n\n**步骤**：\n1. 输入：`Hello`\n2. 按下 `Backspace` 3 次\n3. 预期结果：`He`\n\n**备选操作**：\n- 按 `Home` 移到开始\n- 按 `End` 移到结尾\n- 按 `Delete` 删除前面字符\n\n**预期结果**：\n✅ 所有编辑操作正常\n\n---\n\n### 场景 3: 复制粘贴\n\n**步骤**：\n1. 准备一个有效授权码（至少 20 字符）\n2. 在系统中复制：`Ctrl+C`\n3. 切换到游戏窗口\n4. 点击授权码输入框\n5. 粘贴：`Ctrl+V`\n\n**预期结果**：\n- 授权码完整显示在输入框\n- 与剪贴板内容一致\n\n**常见问题**：\n- 粘贴无反应 → 检查 ImeMode 设置\n- 乱码 → 检查字符编码\n\n---\n\n### 场景 4: 中文输入法（可选）\n\n**步骤**：\n1. 切换输入法为中文\n2. 尝试输入拼音\n\n**预期结果**：\n- 可能无法输入（WH_KEYBOARD Hook 局限）\n- 属于已知限制，可接受\n\n**备注**：\n- 当前修复主要针对英文/ASCII\n- 完整 IME 支持需要额外实现\n\n---\n\n### 场景 5: 特殊字符\n\n**步骤**：\n输入以下序列：\n```\n1. 数字：0123456789\n2. 大写：ABCDEFGHIJKLMNOPQRSTUVWXYZ\n3. 小写：abcdefghijklmnopqrstuvwxyz\n4. 符号：!@#$%^&*()_+-=[]{}|;:',.<>?/\\\n```\n\n**预期结果**：\n- ✅ 数字、大小写、基本符号输入正常\n- ❓ 某些符号可能依赖键盘布局\n\n---\n\n### 场景 6: 全选与批量操作\n\n**步骤**：\n1. 输入：`TestAuthorizationCode123`\n2. 按 `Ctrl+A` 全选\n3. 按 `Backspace` 清空\n4. 重新输入\n\n**预期结果**：\n- ✅ 全选状态可见（通常高亮）\n- ✅ 删除清空整个输入框\n- ✅ 重新输入正常\n\n---\n\n### 场景 7: 快速连续输入\n\n**步骤**：\n1. 快速连续打字（每秒 10+ 个字符）\n2. 输入 100 个字符以上\n3. 观察是否有字符丢失\n\n**预期结果**：\n- ✅ 所有字符正确显示\n- ✅ 顺序正确\n- ✅ 无丢失\n\n**性能指标**：\n- 输入延迟：< 50ms（应不可感知）\n- 帧率：保持 60 FPS\n\n---\n\n### 场景 8: 多窗口焦点切换\n\n**步骤**：\n1. 打开授权窗口\n2. 开始输入\n3. Alt+Tab 切换到其他窗口\n4. 再切换回来\n5. 继续输入\n\n**预期结果**：\n- ✅ 焦点切换正常\n- ✅ 重新回到窗口后可继续输入\n- ✅ 内容保留\n\n---\n\n### 场景 9: 超长输入\n\n**步骤**：\n1. 输入超过 500 字符\n2. 观察输入框滚动/折行行为\n\n**预期结果**：\n- ✅ 输入框能处理长文本\n- ✅ 不崩溃\n- ✅ 可以继续编辑\n\n---\n\n## 自动化测试脚本（可选）\n\n### 使用 AutoHotkey 测试\n\n```ahk\n; test_text_input.ahk\n; 测试 Hook 文本输入\n\nSetBatchLines -1\nSetKeyDelay 50\n\nMsgBox 点击确定后开始测试\\n请在游戏中点击授权码输入框\nWinWait ahk_exe game.exe  ; 等待游戏窗口\n\n; 测试 1: 基础输入\nSend test123ABC\nSleep 100\nSend {Home}\nSend {Backspace}{Backspace}{Backspace}\nSleep 100\n\n; 测试 2: 快速输入\nLoop 100 {\n    Send % Chr(65 + Mod(A_Index, 26))  ; A-Z\n}\nSleep 100\n\n; 测试 3: 全选删除\nSend ^a\nSleep 50\nSend {Delete}\nSleep 100\n\nMsgBox 测试完成！\\n检查输入框是否正常运作\n```\n\n---\n\n## 故障排查\n\n### 症状 1: 无法输入任何字符\n\n**可能原因**：\n1. Hook 未成功安装\n2. ImGui 上下文未初始化\n3. 输入框未获得焦点\n\n**排查步骤**：\n```cpp\n// 添加调试日志\nLOG_INFO(\"KeyboardHook called, vkey={}, wParam={}\", vkey, wParam);\nLOG_INFO(\"ImGui context: {}\", ImGui::GetCurrentContext() != nullptr);\nLOG_INFO(\"IO.WantTextInput: {}\", ImGui::GetIO().WantTextInput);\n```\n\n---\n\n### 症状 2: 部分字符无法输入\n\n**可能原因**：\n1. 字符不在支持范围（0x30-0x5A）\n2. 键盘布局不同\n3. ToUnicodeEx 返回 0\n\n**修复方案**：\n```cpp\n// 扩大支持范围\nif (vkey >= 0x20 && vkey <= 0x7E) {  // 更广的范围\n    // ...\n}\n```\n\n---\n\n### 症状 3: 输入延迟\n\n**可能原因**：\n1. Hook 中执行过重的操作\n2. ImGui 渲染卡顿\n3. 系统资源不足\n\n**优化方案**：\n```cpp\n// 减少 Hook 中的操作\n// 避免在 Hook 中调用复杂函数\n// 确保 ToUnicodeEx 快速返回\n```\n\n---\n\n### 症状 4: 特定键无法工作\n\n**可能原因**：\n1. 键不在转换范围\n2. 键盘布局特殊\n3. IME 干扰\n\n**调试方法**：\n```cpp\n// 记录所有按键\nLOG_INFO(\"Key pressed: vkey=0x{:X}, scanCode=0x{:X}\", vkey, scanCode);\n\n// 检查 ToUnicodeEx 返回值\nLOG_INFO(\"ToUnicodeEx result: {}, char: {}\", result, outChar[0]);\n```\n\n---\n\n## 性能测试\n\n### 测试指标\n\n| 指标 | 期望值 | 测量方法 |\n|------|--------|----------|\n| 输入延迟 | < 50ms | 从按键到屏幕显示的时间 |\n| 丢帧率 | < 1% | 输入时的 FPS 稳定性 |\n| Hook 调用频率 | ~100/秒 | 正常打字速度 |\n| CPU 占用增加 | < 0.5% | 性能监视器 |\n\n### 测试工具\n\n**FPS 监视**：\n```cpp\n// 在渲染循环中添加\nstatic float fps = 0;\nstatic auto lastTime = std::chrono::high_resolution_clock::now();\n\nauto now = std::chrono::high_resolution_clock::now();\nauto delta = std::chrono::duration_cast<std::chrono::milliseconds>(now - lastTime).count();\nif (delta > 1000) {\n    LOG_INFO(\"FPS: {}\", fps);\n    fps = 0;\n    lastTime = now;\n} else {\n    fps += 1000.0f / 16.67f;  // 假设 60 FPS\n}\n```\n\n---\n\n## 验收标准\n\n✅ **通过测试**（需要满足）：\n1. 所有 ASCII 字符可正常输入\n2. Backspace、Delete、Home、End 正常\n3. Ctrl+A、Ctrl+V 正常\n4. 无字符丢失\n5. 无显著延迟\n6. 无崩溃\n\n⚠️ **已知限制**（可接受）：\n1. 中文输入法支持不完整\n2. 某些特殊键可能需要扩展支持\n3. 非英文键盘布局可能有差异\n\n---\n\n## 提交前检查清单\n\n- [ ] 编译无错误\n- [ ] 至少 3 个不同 DirectX 应用测试通过\n- [ ] 文本输入、删除、粘贴都正常\n- [ ] 按钮点击仍正常\n- [ ] 无新的崩溃或错误\n- [ ] 日志输出正常\n- [ ] FPS 未下降\n\n---\n\n## 问题反馈模板\n\n如果修复后仍有问题，请提供：\n\n```\n【问题描述】\n在 [应用名称] 中无法输入 [具体字符/操作]\n\n【重现步骤】\n1. ...\n2. ...\n3. ...\n\n【预期行为】\n...\n\n【实际行为】\n...\n\n【日志输出】\n(贴上相关日志)\n\n【系统信息】\n- Windows 版本：\n- DirectX 版本：\n- 键盘布局：\n- 输入法：\n```\n\n---\n\n## 相关文档\n\n- [HOOK_INPUT_FIX_REPORT.md](HOOK_INPUT_FIX_REPORT.md)\n- [HOOK_INPUT_FIX_SUMMARY.md](HOOK_INPUT_FIX_SUMMARY.md)\n- [HOOK_COMPARISON_ANALYSIS.md](HOOK_COMPARISON_ANALYSIS.md)\n- [HOOK_INPUT_QUICK_REFERENCE.md](HOOK_INPUT_QUICK_REFERENCE.md)\n"
