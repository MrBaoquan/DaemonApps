# LicHper 中文编码优化和功能增强说明

## 一、中文字符编码深度优化

### 1.1 问题分析

项目中存在多层次的编码问题：

#### **根本原因**
- **源代码编码问题**：部分 `.cpp` 文件缺少 `#pragma execution_character_set("utf-8")` 指令
- **字符集配置**：项目使用 `MultiByte` 字符集，源码中的中文字符串会被编译器按系统默认编码（GBK）处理
- **BSTR转换问题**：之前的 `string2BSTR` 和 `BSTR2String` 使用简单的 `_bstr_t` 转换，未正确处理 UTF-8 编码
- **不必要的编码转换**：数据流中存在多次 GBK ↔ UTF-8 转换，导致编码混乱

#### **数据流分析（优化前）**
```
源码 "无效许可证" (GBK编译) 
  → std::string (GBK) 
  → GbkToUtf8 (转UTF-8) 
  → string2BSTR (错误的转换) 
  → C# (乱码)
```

### 1.2 优化方案

#### **1. 添加 UTF-8 编译指令**
```cpp
// validator.cpp 和 WatermarkRenderer.cpp 开头添加
#pragma execution_character_set("utf-8")
```

**作用**：确保源代码中的中文字符串在编译时被正确编译为 UTF-8 编码

#### **2. 重写 BSTR 转换函数**
```cpp
// 修复前（错误）
BSTR string2BSTR(const std::string& str) {
    return SysAllocString(_bstr_t(str.c_str()));  // 未处理编码
}

// 修复后（正确）
BSTR string2BSTR(const std::string& str) {
    if (str.empty()) return SysAllocString(L"");
    
    // UTF-8 → Unicode (wchar_t)
    int len = MultiByteToWideChar(CP_UTF8, 0, str.c_str(), -1, NULL, 0);
    wchar_t* wstr = new wchar_t[len];
    MultiByteToWideChar(CP_UTF8, 0, str.c_str(), -1, wstr, len);
    
    BSTR bstr = SysAllocString(wstr);
    delete[] wstr;
    return bstr;
}
```

**关键点**：
- 明确使用 `CP_UTF8` 代码页
- 通过 Unicode (wchar_t) 作为中间格式
- BSTR 本质是 Unicode 字符串

#### **3. 移除不必要的编码转换**
```cpp
// 修复前
_userInfo.error = GbkToUtf8("无效许可证");  // 不需要！

// 修复后
_userInfo.error = "无效许可证";  // 已经是UTF-8（因为有编译指令）
```

#### **4. 删除冗余的 GbkToUtf8 函数**
- 从 `WatermarkRenderer.cpp` 中移除 `GbkToUtf8` 函数
- 移除所有 `GbkToUtf8()` 调用
- 直接使用字符串，编译器会自动处理为 UTF-8

### 1.3 优化效果

#### **数据流（优化后）**
```
源码 "无效许可证" (UTF-8编译) 
  → std::string (UTF-8) 
  → string2BSTR (UTF-8→Unicode) 
  → BSTR (Unicode) 
  → C# string (自动处理) 
  → 正确显示中文
```

#### **修改文件清单**
1. `validator.cpp` - 添加 UTF-8 编译指令，重写 BSTR 转换函数
2. `WatermarkRenderer.cpp` - 添加 UTF-8 编译指令，移除 GbkToUtf8
3. `WatermarkRenderer.h` - 移除 GbkToUtf8 声明
4. `imgui_main.cpp` - 已有 UTF-8 编译指令（无需修改）

```cpp
void WatermarkRenderer::RenderWatermarkText(const std::string& text, ...) {
    // 如果文本为空，不渲染

    std::string text = config.title;
```

### 2.2 图片水印动画移动

#### **新增配置项**
```cpp
// WatermarkConfig.h
struct WatermarkConfig {
    // ... 其他配置
    bool imageAnimate = false;  // 图片是否启用动画移动

```

#### **实现逻辑**
```cpp
void WatermarkRenderer::RenderWatermarkImage(float windowWidth, float windowHeight) {
    // 如果启用了图片动画
    if (config.imageAnimate) {
        // 碰撞边界反弹动画（与文字动画相同）
        if (m_imagePosition.x + imageSize.x + 10 >= windowWidth) 
            m_imageVelocity.x = -1;
        if (m_imagePosition.x <= 0) 
            m_imageVelocity.x = 1;
        if (m_imagePosition.y + imageSize.y + 10 >= windowHeight) 
            m_imageVelocity.y = -1;
        if (m_imagePosition.y <= 0) 
            m_imageVelocity.y = 1;
        
        m_imagePosition.x += m_imageVelocity.x;
        m_imagePosition.y += m_imageVelocity.y;
        
        posX = m_imagePosition.x;
        posY = m_imagePosition.y;
    } else {
        // 静态定位（使用 imageAlign 配置）
        // ... 原有对齐逻辑
    }
}
```

#### **状态管理**
```cpp
// WatermarkRenderer.h
class WatermarkRenderer {
private:
    // 图片动画状态
    ImVec2 m_imagePosition = ImVec2(100, 100);
    ImVec2 m_imageVelocity = ImVec2(1, 1);
};
```

#### **配置加载**
```cpp
// RenderManager.cpp
bool RenderManager::ParseIniConfig(const std::string& iniPath) {
    // ...
    if (wm.has("image_animate")) {
        m_config.imageAnimate = (wm["image_animate"] == "true");
    }
}
```

#### **配置示例**

## 四、技术要点总结

### 4.1 编码处理最佳实践

1. **统一使用 UTF-8**
   - 源码编译：`#pragma execution_character_set("utf-8")`
   - 内部处理：所有 `std::string` 都是 UTF-8
   - 外部交互：通过 BSTR 转换为 Unicode

2. **避免多次转换**
   - 不要在已经是 UTF-8 的数据上再调用 `GbkToUtf8`
   - 信任编译器和编译指令

3. **明确编码路径**
   ```
   源码(UTF-8) → std::string(UTF-8) → BSTR(Unicode) → C#(UTF-16)
   ```

### 4.2 水印渲染架构

```
RenderManager
    ├── ParseIniConfig()      # 加载配置
    ├── CreateRenderer()      # 创建渲染器
    └── WatermarkRenderer     # 共享渲染组件
            ├── RenderWatermarkText()   # 文字渲染（支持空标题）
            └── RenderWatermarkImage()  # 图片渲染（支持动画）
```

### 4.3 性能优化

- 图片动画每帧仅移动 1 像素（平滑流畅）
- 动画状态持久化（避免重复计算）
- 配置通过互斥锁保护（线程安全）
