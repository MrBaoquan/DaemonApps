# LicHper 图片水印功能使用说明

## 📝 功能概述

LicHper 现已支持**图片水印**功能，可以在授权验证界面显示自定义图片，并支持图片与文字的混合显示。

**文字渲染优化**: 已启用字体抗锯齿（3x 过采样 + 亚像素渲染），文字边缘平滑无锯齿。

---

## 🎨 支持的图片格式

- **BMP** (24位/32位) ✅
- **PNG** (1/2/4/8/16位) ✅
- **JPG/JPEG** (Baseline & Progressive) ✅
- **TGA** ✅
- **GIF** ✅
- **PSD** (8/16位) ✅
- **HDR** (Radiance rgbE) ✅
- **PIC** (Softimage PIC) ✅
- **PNM** (PPM/PGM) ✅

> **注意**: 已集成官方完整版 stb_image v2.30，支持所有主流图片格式!

---

## 📁 图片存放位置

水印图片默认存放在用户目录下的 `.lichper` 文件夹中：

```
%USERPROFILE%\.lichper\
    └── watermark.png    (默认水印图片)
```

**路径解析规则**：
- `image_path` 留空 → 自动使用 `.lichper\watermark.png`
- `image_path = logo.png` → 相对路径，解析为 `.lichper\logo.png`
- `image_path = C:\path\to\image.png` → 绝对路径，直接使用

---

## ⚙️ 配置方法

在用户目录下的 `.authrc.ini` 文件中，`[watermark]` 节添加以下配置：

```ini
[watermark]
# 文字水印配置
title = {APPID} Demo Version
font_size = 80
color = #FF6666
animate = true

# 图片水印配置
image_path =               ; 留空=使用.lichper/watermark.png
image_scale = 1            ; 缩放比例，1=原始尺寸
image_alpha = 0.8          ; 透明度
image_align = top-center   ; 对齐方式
image_padding_x = 50       ; 水平边距
image_padding_y = 50       ; 垂直边距
```

---

## 📋 配置参数说明

### 图片水印参数

| 参数 | 说明 | 默认值 | 取值范围 |
|------|------|--------|----------|
| `image_path` | 图片路径（支持相对路径或绝对路径） | 空（使用.lichper/watermark.png） | 有效的文件路径 |
| `image_scale` | 缩放比例 | 1（原始尺寸） | 0.1 - 10.0 |
| `image_alpha` | 透明度，**限制0.3-1.0确保可见** | 0.8 | 0.3 - 1.0 |
| `image_align` | 对齐方式 | top-center | 见下表 |
| `image_padding_x` | 水平边距（像素） | 50 | ≥0 |
| `image_padding_y` | 垂直边距（像素） | 50 | ≥0 |

### 对齐方式 (image_align)

| 值 | 说明 | padding 作用 |
|------|------|------|
| `top-left` | 左上角 | X=左边距, Y=上边距 |
| `top-center` | 顶部居中 | Y=上边距 |
| `top-right` | 右上角 | X=右边距, Y=上边距 |
| `center-left` | 左侧居中 | X=左边距 |
| `center` | 屏幕中央 | 边距不生效 |
| `center-right` | 右侧居中 | X=右边距 |
| `bottom-left` | 左下角 | X=左边距, Y=下边距 |
| `bottom-center` | 底部居中 | Y=下边距 |
| `bottom-right` | 右下角 | X=右边距, Y=下边距 |

### 尺寸控制

- **image_scale = 1** → 原始尺寸
- **image_scale > 1** → 放大（如 2 = 放大2倍）
- **image_scale < 1** → 缩小（如 0.5 = 缩小一半）

## 💡 使用示例

### 示例 1: 使用默认水印（最简配置）

```ini
[watermark]
title = {APPID} 试用版
; 留空image_path，自动使用 .lichper/watermark.png
image_path = 
image_scale = 1
image_alpha = 0.8
```

### 示例 2: 右下角小水印（常用）

```ini
[watermark]
title = {APPID} 试用版
image_path = logo.png       ; 相对路径，解析为 .lichper/logo.png
image_scale = 0.5
image_alpha = 0.8
image_align = bottom-right
image_padding_x = 30
image_padding_y = 30
```

### 示例 3: 顶部居中水印

```ini
[watermark]
title = {COUNTDOWN}
image_path = banner.png     ; 相对路径
image_scale = 0.3
image_alpha = 0.9
image_align = top-center
image_padding_y = 50
```

### 示例 4: 使用绝对路径

```ini
[watermark]
title = 未授权版本
font_size = 60
image_path = C:\watermarks\warning.png    ; 绝对路径
image_scale = 0.8
image_alpha = 0.7
image_align = bottom-left
image_padding_x = 20
image_padding_y = 20
```

### 示例 5: 屏幕中央大水印

```ini
[watermark]
title = {APPID} DEMO
image_path =              ; 使用默认 watermark.png
image_scale = 2           ; 放大2倍
image_alpha = 0.5
image_align = center
```

## 🔧 技术说明

### 实现原理

1. **图片加载**: 使用 `stb_image` 库将图片文件加载为 RGBA 数据
2. **纹理创建**: 通过 DirectX11 创建 2D 纹理和着色器资源视图
3. **ImGui渲染**: 使用 `ImGui::Image()` 在透明窗口中渲染图片
4. **资源管理**: 程序退出时自动释放纹理资源

### 资源要求

- DirectX 11 支持
- 图片文件需存在于指定路径
- 建议图片尺寸不超过 2048x2048

---

## ⚠️ 注意事项

1. **路径规则**: 
   - 留空 → 使用 `.lichper/watermark.png`
   - 相对路径（如 `logo.png`）→ 解析为 `.lichper/logo.png`
   - 绝对路径（如 `C:\...`）→ 直接使用
2. **文件存在性**: 如果图片文件不存在，将只显示文字水印
3. **性能影响**: 大尺寸图片可能影响渲染性能，建议使用合适尺寸
4. **透明度限制**: `image_alpha` 值限制在 0.3-1.0 之间，**确保水印始终可见**
5. **混合显示**: 图片和文字可以同时显示，互不冲突
6. **缩放控制**: 
   - `image_scale = 1` 为原始尺寸
   - `image_scale > 1` 放大，如 2 表示放大2倍
   - `image_scale < 1` 缩小，如 0.5 表示缩小一半
7. **对齐与边距**:
   - `image_align` 决定图片相对于窗口的位置
   - `image_padding_x/y` 决定图片距离对应边界的距离
   - 例如 `bottom-right` + `padding_x=30` 表示图片右边距离窗口右边30像素
8. **授权保护**: 透明度最低限制为 0.3，确保授权提示始终可见，防止完全隐藏

## 🎯 常见问题

**Q: 图片不显示怎么办?**  
A: 检查以下项目：
- 图片路径是否正确
- 文件是否存在
- 图片格式是否支持（支持BMP/PNG/JPG/GIF/TGA/PSD/HDR/PIC/PNM）
- 查看程序是否有文件访问权限

**Q: 图片显示变形？**  
A: 
- 使用 `image_scale` 缩放可保持原始比例
- 或只设置 `image_width` 或 `image_height` 之一
- 避免同时设置 width 和 height 为不同比例的值

**Q: 如何使用图片原始尺寸？**  
A: 设置 `image_width = 0` 和 `image_height = 0` 即可

**Q: 如何让图片显示在右下角，距离边界30像素？**  
A: 设置 `image_align = bottom-right`，`image_padding_x = 30`，`image_padding_y = 30`

**Q: padding 参数什么时候生效？**  
A: 
- 水平方向：`left` 时表示左边距，`right` 时表示右边距，`center` 时不生效
- 垂直方向：`top` 时表示上边距，`bottom` 时表示下边距，`center` 时不生效

**Q: 可以完全隐藏水印吗？**  
A: **不可以**。透明度限制在 0.3-1.0，文字水印始终显示，这是授权系统的安全设计

**Q: 可以显示动态图片吗？**  
A: 当前版本不支持GIF动画，仅支持静态图片
