## 🔧 参数调整指南

### 图片尺寸调整
```ini
image_width = 150   # 建议范围: 50-500
image_height = 150  # 建议范围: 50-500
```

### 透明度调整
```ini
image_alpha = 0.7   # 范围: 0.0(完全透明) - 1.0(完全不透明)
```
- 0.5 - 半透明，不影响视线
- 0.7 - 较清晰，推荐值
- 1.0 - 完全不透明

### 位置调整
```ini
image_position = top  # center/top/bottom/left/right
```

```ini
image_width = 200
image_height = 200
image_alpha = 1.0
image_position = center
```

## ⚠️ 常见问题排查

### 图片不显示
1. 检查路径是否正确（使用绝对路径）
2. 确认文件存在: `Test-Path "路径"`
3. 检查文件格式是否支持
4. 查看文件大小是否合理（建议<2MB）

### 图片显示变形
调整 `image_width` 和 `image_height` 保持原图比例:
```ini
# 原图 400x300 (4:3)
image_width = 200
image_height = 150
```

### 透明度无效
- BMP格式不支持透明通道，使用 `image_alpha` 调整
- PNG格式可同时使用图片透明度和 `image_alpha`

## 🎯 性能优化建议

3. **格式选择**:

   - 需要透明 → PNG
   - 照片类型 → JPG
